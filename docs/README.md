## Archive

`archive/` contains superseded briefs, research, mockups, task cards, icon concepts, and QA notes. Read `archive/README.md` before using any archived material.

Archive content is retained for provenance only. It must not override current source, approved design references, or active specifications.

## Documentation Rules

- Use **Life Grid** for the user-facing feature.
- Use `WeekArchive*` only for actual internal symbols, paths, stores, routes, and persistence seams.
- Scope every “source of truth” claim: visual, interaction, component API, brand, target configuration, or verification evidence.
- Link to `CURRENT_SOURCES.md` instead of copying a second, drifting master list.
- Move superseded material to `archive/` rather than leaving it beside active specifications.
