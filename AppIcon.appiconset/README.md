# Mori App Icon

Active direction: botanical paper-linework on watercolor paper.

## Active Set

`Contents.json` points to the `*_paper_linework.png` family for iOS and Android icon slots.

Primary masters:

- `icon_1024_paper_linework.png`

Generated active sizes:

- `icon_*_paper_linework.png`
- `android_icon_*_paper_linework.png`

## Regeneration

Run from this directory:

```sh
./generate_icons.sh
```

The script intentionally does not generate archived legacy directions or older
non-paper marks.
